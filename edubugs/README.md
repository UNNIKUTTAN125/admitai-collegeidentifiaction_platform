### ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start local development server (with HMR)
npm run dev

# 3. Compile TypeScript & bundle for production
npm run build

# 4. Preview production build locally
npm run preview
```

---

### 🛠️ Key Scripts
- `npm run dev`: Starts Vite local dev server at `http://localhost:5173/`
- `npm run build`: Runs TypeScript compiler (`tsc -b`) and Vite production bundler
- `npm run lint`: Runs Oxlint static code analysis
- `npm run preview`: Spins up a local static server to test production build output
